
\# My Personal Finance Assistant



\#### Video Demo: <URL HERE>



\#### Description:



My Personal Finance Assistant is a web-based application designed to help users manage their monthly salary, investments, and expenses. The main goal of this project is to make personal finance tracking simple and easy to understand.



The application allows users to enter their monthly salary and the amounts they spend on investments, insurance, shopping, and other expenses. It then calculates the percentage of the salary used for each category. It also calculates the remaining balance after subtracting all the entered amounts from the salary.



The application includes a table with separate rows for all twelve months of the year. This allows users to organize their financial information month by month. The results update automatically when users change the entered amounts, making it easier to track their finances without doing the calculations manually.



I created this project to help people understand how they use their money each month. By showing the salary, expenses, percentages, and remaining balance in one place, the application gives users a clearer view of their monthly finances.



\*\*Technologies Used\*\*



I used Python and Flask to run the web application. HTML provides the structure of the web page, while CSS controls its design and appearance. JavaScript performs the calculations and updates the results when the user changes the input values.



\*\*Project Files\*\*



\- `app.py` contains the Python code that starts the Flask application and displays the main page.

\- `templates/index.html` contains the HTML structure of the application.

\- `static/style.css` contains the CSS used to style the page and its table.

\- `static/script.js` contains the JavaScript code that calculates the remaining balance and expense percentages.



\*\*Calculations\*\*



The application calculates the remaining balance by subtracting investments, insurance, shopping, and other expenses from the monthly salary.



Remaining Balance = Salary − Investment − Insurance − Shopping − Other Expenses



It calculates the percentage for each category by dividing the amount by the salary and multiplying the result by 100.



Percentage = (Amount ÷ Salary) × 100



The application should also avoid dividing by zero when the salary is zero.



\*\*Design Choices\*\*



I chose a table layout because it keeps the financial information organized and easy to read. I separated the application into different files to keep the Python, HTML, CSS, and JavaScript code organized. I also used automatic calculations so users do not need to calculate each percentage or the remaining balance themselves.



Working on this project helped me practise programming, basic financial calculations, and web development. It also helped me understand how different technologies can work together to create a useful application.



In the future, I would like to add features that allow users to save their financial records, compare expenses across different months, and view their spending through charts.



Overall, My Personal Finance Assistant is a simple tool for tracking monthly income and expenses and understanding how much money remains after spending and investing.
